# Átrio Advocacia

Abra `index.html` no navegador para testar. Os dados e perfis de exemplo podem ser editados em `assets/conteudo.js`. As páginas ficam nos arquivos HTML e o visual em `assets/site.css`.

## Publicar a versão estática na Vercel

1. Envie o conteúdo desta pasta para um repositório. Se o repositório também incluir a pasta externa, selecione `atrio-advocacia` em **Root Directory** na Vercel.
2. Importe o repositório na Vercel com o preset **Other**. O arquivo `vercel.json` define o comando que prepara a versão estática e a pasta de saída. Clique em **Deploy** quando quiser publicar.
3. Abra o endereço gerado e confira as quatro páginas, as imagens e a navegação.

O formulário permanece em modo de teste na Vercel. O painel PHP e o envio real de e-mail exigem outra configuração de hospedagem. Para instalar a versão completa em PHP, consulte o guia na pasta acima. A versão inicial contém marca, perfis e contatos demonstrativos.
